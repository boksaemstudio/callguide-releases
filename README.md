# 통화후 문자

![통화후 문자 로고](icon-512.png)

사진 두 장과 안내 문구를 문자 앱으로 넘기는 Android 앱입니다. 사진과 문구는 휴대전화에서 바꿀 수 있습니다.

Android 설치 파일과 사용 안내를 제공합니다.

## Android 설치 파일

[통화후 문자 1.0.0 APK 받기](https://github.com/boksaemstudio/callguide-releases/releases/download/v1.0.0/callguide-1.0.0.apk)

현재 사전 배포본입니다. 실제 갤럭시에서 통화 종료 후 받는 번호·사진 두 장·문구가 함께 들어가는지와 실제 전송·수신 여부는 아직 검증하지 않았습니다. Google Play 승인 완료를 뜻하지 않습니다.

Android 11 이상에서 사용할 수 있습니다. 문자 앱과 기기에서 제공하는 기능에 따라 작동 방식이 달라질 수 있습니다.

## 사용하는 순서

1. 보낼 사진 두 장을 고르고 안내 문구를 저장합니다.
2. ‘직접 시험해 보기’에서 문자 작성 화면에 받는 번호·사진 두 장·문구가 모두 들어가는지 확인합니다. 이 확인 전에는 통화 후 자동 연결을 켤 수 없습니다.
3. 통화 후 자동 연결을 사용하려면 설명을 읽고 발신자 ID·스팸 앱 역할을 선택한 뒤 자동 연결을 켭니다. 기존 스팸 확인 앱의 역할을 대신하므로 선택 전 확인하세요.
4. 3초 이상 연결된 통화가 끝나면 기본 문자 앱으로 안내를 넘깁니다. 받은 통화와 건 통화 모두 대상이며, 한국 휴대전화번호만 지원합니다.
5. 받는 번호와 첨부 내용을 확인한 뒤 문자 앱에서 직접 전송합니다. 앱이 문자를 자동 발송하거나 수신 여부를 확인하지 않습니다.

부재중·거절된 통화와 짧은 통화는 자동 연결에서 제외합니다. 기본 문자 앱이나 버전이 바뀌면 작성 화면을 다시 확인해야 합니다. 문자·MMS·RCS 요금은 통신사와 요금제에 따릅니다.

사진과 안내 문구는 이 휴대전화에 저장합니다. 앱은 로그인·광고·통화 녹음·자체 서버 업로드를 사용하지 않습니다.
